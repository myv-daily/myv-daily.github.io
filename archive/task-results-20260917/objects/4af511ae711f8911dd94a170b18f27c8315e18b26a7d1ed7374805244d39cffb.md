## 结论

本轮存在值得公开写作 Agent 考虑的实质变化，核心不是单日上涨，而是公司在 8 月 31 日 18:56、港股收市后披露的中期业绩首次给出了此前长期缺失的 API 商业化与单位经济证据。2026 年上半年收入 9.54 亿元人民币，同比增长 399.7%，已经超过 2025 年全年 7.24 亿元；其中开放平台及 API 收入 8.25 亿元，同比增长 2,735.7%，占收入 86.5%，云端业务毛利率由 -0.4% 转为 24.6%。截至公告日，MaaS 平台 Token 调用量较年初超过 40 倍，平均 API 售价同时上涨约 101%，GLM MaaS 企业及开发者用户由 6 月底超过 580 万增至公告日超过 740 万。此前“产品迭代能否转化为调用、收入与毛利”的核心疑问取得显著正面进展，且增长不是单纯以降价换量。

但盈利与资金消耗没有同步转正。上半年经调整净亏损 19.64 亿元，同比扩大 12.1%，研发费用 21.31 亿元，同比增长 33.6%，分别约为收入的 206%和 223%；整体毛利率因收入转向较低毛利的云端业务而由 50.0%降至 26.4%。报表净亏损收窄 12.1%至 20.72 亿元，主要受上市后投资者金融工具账面变动损失大幅减少影响，不能替代经调整亏损口径。应收及票据净额由 2025 年末 3.03 亿元增至 7.83 亿元，计算服务费等预付款由 1.16 亿元增至 12.44 亿元；银行贷款由 6.90 亿元升至 22.25 亿元。1 月 IPO 和新增借款令 6 月底现金升至 39.94 亿元，7 月配售又取得约 313.75 亿港元净额，短期融资风险显著下降，但规模化盈利仍未验证。

价格确认是积极但不宜解释过度。8 月 31 日智谱收涨 9.63%至 1,195 港元，收复 1,129 港元并突破 8 月 27—28 日的 1,160—1,171 港元高位，成交量 1,108 万股，为前一交易日 2.87 倍。相对恒生科技指数的 0.32%涨幅明显走强；但同日 MiniMax 上涨 16.18%，智谱反而跑输同业 6.55 个百分点，说明大模型板块共振很强。更关键的是，中期业绩公告在收市后约 2 小时 48 分发布，当日股价不可能是市场对财报细节的反应；它至多反映 GLM-5.3 权重开放、财报预期与板块风险偏好。下一个交易日才是中报新增事实的首次市场检验。

## 本轮增量事实与判断

### 1. API 商业化从待验证问题变为有收入、价格和毛利三重证据

- 上半年总收入 9.539 亿元，同比增长 399.7%；开放平台及 API 收入 8.252 亿元，同比增长 2,735.7%，占比由上年同期 15.2%升至 86.5%。云端部署收入与开放平台及 API 收入口径均为 8.252 亿元，表明公司收入主轴已由一次性私有化交付实质转向按调用或订阅收费的云端服务。
- 截至公告日，MaaS Token 调用量较 2026 年初增长超过 40 倍，Coding Plan 调用量增长超过 23 倍；同期平均 API 售价上涨约 101%，Coding Plan 订阅价格也上调。公司没有披露起始绝对 Token 数、净收入留存或付费用户数，40 倍不能直接外推收入，但“量价齐升”至少否定了增长完全由免费或大幅降价促成的弱解释。
- 开放平台及 API 毛利由上年同期负 11.6 万元转为 2.029 亿元，毛利率由 -0.4%升至 24.6%，较 2025 全年 18.9%再提高约 6 个百分点。公司归因于规模效应、提价和推理工程优化；同时披露年初以来单位 Token 推理成本下降 80%，并已在超过 10 万颗国产芯片集群上进行大规模推理。收入、售价和毛利率同向改善，使“国产算力适配是否具有经济性”第一次获得报表层面的间接支持，而不再只有部署路径。
- 用户数由 6 月底超过 580 万增至公告日超过 740 万，约两个月增加至少 160 万或 27.6%。该数字混合企业与开发者，也未披露活跃、付费和留存，不能直接当客户数；但与 Token 和 API 收入增长方向一致，支持生态扩张并非只有模型仓库热度。
- GLM-5.3 和 GLM-5.3-Flash 均在 6 月 30 日之后发布，因此上述上半年收入和毛利改善主要验证的是此前模型与 Coding Plan，而非两款新模型的贡献。新模型能否延续量价与毛利改善仍需三季度数据确认。

### 2. 规模扩大尚未带来调整后亏损收窄，经营投入与资产占用快速增加

- 报表净亏损由 23.58 亿元收窄至 20.72 亿元，下降 12.1%；但经调整净亏损由 17.52 亿元扩大至 19.64 亿元，上升 12.1%。差异主要来自投资者金融工具账面变动损失由 4.293 亿元降至 0.221 亿元，原因是上市后相关赎回权终止并转为权益。判断经营改善应优先采用经调整口径。
- 研发费用 21.31 亿元，同比增长 33.6%，是收入的 2.23 倍；销售及营销费用和行政费用分别下降至 1.78 亿元和 1.03 亿元，说明亏损核心仍是模型研发而非销售扩张。毛利 2.52 亿元虽增长 163.7%，仍不足以覆盖研发投入。
- 整体毛利率由 50.0%降至 26.4%，这是低毛利云端业务占比快速上升的结构性结果。云端毛利率改善是正面，但企业级智能体毛利率由 64.6%降至 35.6%，通用大模型私有化毛利率由 58.5%降至 42.3%；新增定制交付成本和私有化规模收缩使传统高毛利业务不能提供同等缓冲。
- 贸易及票据应收净额由年末 3.03 亿元增至 7.83 亿元，增幅 158%；其中 6—12 个月账龄净额由 0.31 亿元升至 1.09 亿元，金融资产减值损失同比增长 151.4%至 0.274 亿元。相对 9.54 亿元半年收入，应收占用已较大，需要验证回款质量。
- 计算服务费等预付款由 1.16 亿元增至 12.44 亿元，资本开支由 0.54 亿元增至 3.91 亿元，银行贷款由 6.90 亿元增至 22.25 亿元。公告未提供完整经营现金流量表，不能精确计算上半年经营现金消耗；但预付款、借款、研发与亏损的同步增加说明“毛利转正”尚未变成自我融资。

### 3. 资金安全垫大幅增强，但高估值仍要求远超当前规模的兑现

- 6 月底现金及现金等价物为 39.94 亿元，较年末增加 17.35 亿元，主要来自 IPO 募资和银行借款；同期银行贷款 22.25 亿元，净现金约 17.69 亿元人民币。7 月 13 日完成配售，净募资约 313.75 亿港元，发生在中报期后，尚未进入 6 月底现金余额，但显著延长研发与基础设施投入的资金跑道。
- 8 月 31 日收盘总市值约 5,564 亿港元。即便把上半年收入简单年化至约 19.1 亿元人民币，市销率仍在数百倍量级；且年化忽略高速增长，不能作为预测，只用于显示当前价格已经隐含极高的未来收入与利润预期。新增 313.75 亿港元现金能降低企业价值，但不足以改变估值主要依赖远期兑现的性质。
- 中报证明商业化曲线比上一轮掌握的 2025 年基线强得多，因此不能继续只用 2025 年收入评价公司；但调整后亏损扩大、研发强度超过收入两倍，也不能因 API 毛利转正就外推整体盈利拐点。

### 4. 8 月 31 日放量收复关键位，但主要是板块共振，财报反应尚未发生

- 智谱 8 月 31 日开盘 1,079 港元，最低 1,038、最高及收盘均为 1,195，较前收盘上涨 9.63%；收盘位于日内最高，成交量 1,108 万股，较 8 月 28 日增加 187%。价格重新站上上一轮的 1,129 港元验证位，也越过 1,160—1,171 港元短期高位，前一交易日的突破失败得到修复。
- 相对表现并非公司独有：恒生科技指数仅涨 0.32%，智谱跑赢 9.31 个百分点；MiniMax 同日涨 16.18%，智谱跑输 6.55 个百分点。智谱和 MiniMax 的共同放量大涨更像大模型板块风险偏好回升，GLM-5.3 权重开放可能贡献公司催化，但无法从行情中单独识别。
- 从 8 月 27 日至 31 日，智谱累计上涨约 8.64%，MiniMax 累计约 10.93%，恒生科技指数大致持平。智谱已脱离 1,000—1,129 港元区间上沿，但相对同业不占优，现阶段可上调为“放量重新突破”，尚不足以确认持续独立上行趋势。
- 中期业绩在 18:56 发布，晚于 16:08:50 行情时间戳；因此当日上涨绝不能表述为“中报后上涨”。下一交易日若在 1,171—1,195 港元上方保持强势且相对 MiniMax/恒生科技继续占优，才说明市场认可收入与毛利证据；若高开回落跌回 1,129 以下，则可能是板块行情已提前透支。

### 5. GLM-5.3 开放后的生态有活跃迹象，但独立复现仍不足

- Hugging Face 官方仓库在窗口内合并了 HLE、DeepSWE、Terminal-Bench 2.1/3.0 等社区评测结果，并在 8 月 31 日补充或调整评测 harness 说明；仓库仍公开、非 gated，权重交付状态未反转。
- 这些更新提高了评测方法透明度，也显示社区开始参与仓库维护，但结果被合入公司官方模型卡，并不等于完全独立的本地部署复现。截止时仍未获得可核验的第三方吞吐、稳定性、国产芯片硬件规格和真实推理成本报告。
- 本轮中报披露的 10 万颗以上国产芯片集群、单位 Token 成本下降 80%和 API 毛利率转正，比下载量或点赞更有经营价值；但均由公司自报，后续仍需框架厂商、云平台或客户侧证据交叉验证。

## 对历史待验证问题的进展

1. **API 调用、收入与单位经济**：重大正面进展。上半年 API 收入 8.25 亿元、占比 86.5%，公告日 Token 调用量较年初超 40 倍、平均售价升约 101%，API 毛利率转正至 24.6%。仍缺绝对 Token 量、付费用户、留存、客户集中度与三季度延续性。
2. **调整后盈利能力**：负面/未完成。经调整净亏损同比扩大 12.1%至 19.64 亿元；毛利改善尚不能覆盖 21.31 亿元研发费用。
3. **国产算力适配与经济性**：显著进展。公司披露超过 10 万颗国产芯片集群和单位 Token 推理成本下降 80%，并与云端毛利率转正相印证；缺第三方硬件、吞吐与成本复核。
4. **GLM-5.3/Flash 商业贡献**：仍待验证。两款模型均在中报期后发布，上半年高增长不能归因于它们；公告日用户与调用数据可能部分包含发布后贡献，但未拆分。
5. **旗舰权重开放与独立复现**：开放状态保持，社区评测与 harness 信息增加；尚无足够独立部署结果。
6. **1,129 港元支撑与趋势**：正面进展。8 月 31 日放量收复并升至 1,195 港元，但同日跑输 MiniMax，且中报尚未经历交易，需下一交易日确认。
7. **现金消耗与融资安全垫**：安全垫大幅增强。7 月配售净募资约 313.75 亿港元尚未计入 6 月底余额；经营现金消耗缺完整现金流表，贷款及计算服务预付款显著增加。
8. **应收与回款质量**：新增风险线索。应收净额增至 7.83 亿元、部分账龄拉长且减值增加，需观察下半年回款。
9. **科创板发行与 1GW 数据中心**：本轮无新增正式进展。

## 风险与下一轮观察

下一交易日是中期业绩首次价格验证，优先观察 1,171—1,195 港元是否转为支撑、成交是否继续放大，以及相对 MiniMax和恒生科技指数的强弱。若价格在中报后显著走弱，说明市场更关注调整后亏损、资金消耗或高估值；若相对同业继续走强，才可认为收入结构和 API 毛利转正获得独立定价。

基本面下一轮应追踪四组可量化证据：第一，三季度 API 收入、绝对 Token 调用、平均售价、Coding Plan 付费与留存，确认 GLM-5.3/Flash 是否延续而非替代上半年增长；第二，API 毛利率能否在开放权重可能分流托管调用的情况下继续提高；第三，应收账款回收、计算服务预付款消化、银行贷款与经营现金消耗；第四，10 万颗国产芯片集群的具体芯片构成、利用率、吞吐和单位成本能否获得第三方验证。中报称网络安全之外的法律、金融、教育 Co-work 尚在早期且未产生重大收入，不应提前计入估值。

本轮应提交“yes”。原因是正式中报首次把此前最关键的商业化疑问推进到收入、量价与毛利三重验证，足以改变仅凭产品发布和 2025 年低收入基线形成的判断；同时调整后亏损、研发强度、应收和资金占用又清楚限定了上调幅度。公开写作若采用，应明确区分事件时序：8 月 31 日股价上涨发生在 18:56 中报发布之前，不是业绩后的市场反馈。
