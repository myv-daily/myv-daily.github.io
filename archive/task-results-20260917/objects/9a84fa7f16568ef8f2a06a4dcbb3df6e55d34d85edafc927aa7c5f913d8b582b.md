## 拟公开信息单元

### 1. 《VHOLUME》今日稍晚解锁：把官僚迷宫做成可被速度拆解的跑酷空间（中等篇幅）

- **关键事实**：Steam 当前标注 8 月 21 日发行，09:50 仍为 coming soon、无正式版评价；三名开发者 Nathan Grange、Léonard Lemaitre、Niels Tiercelin 制作，IronEqual 发行。单人核心完整，在线合作、异步幽灵和 Workshop 是附加功能，符合当前范围。
- **作品方向**：玩家为了恢复家庭配给券穿越反乌托邦官僚城市，以跳跃、奔跑、攀爬、滑行和动量寻找捷径；目标时间、幽灵路线与玩家自制关卡让“办一件小事被层层拖延”的叙事空间同时成为技巧表达空间。值得读者知道的不是发售日，而是行政迷宫与速通式破局的结合。
- **待验证**：正式版实际解锁时间；移动是否精确；关卡能否同时服务首次探索和熟练后的破序；故事是否超出氛围包装；Workshop 工具是否首发可用。Demo 只能支撑方向，不能替正式版验收。
- **来源**：[Steam 商店页](https://store.steampowered.com/app/4131730/VHOLUME/)（开发/发行、功能、玩法说明、当前状态）；Steam appdetails API 的 09:50 快照确认 coming soon 与 8 月 21 日日期。
- **历史关系**：五篇历史均未讨论，是本轮新发现。

### 2. 《Taste of the Wind（醉风酒）》把餐馆经营决策接到五年还债与人物结局（简洁至中等）

- **关键事实**：个人开发者一留留自研自发；Steam 标注 8 月 21 日发行，09:50 尚未解锁、无正式版评价，已有 Demo。
- **作品方向**：经营不只由即时做菜组成，还包括月度菜单、菜价、扩建、培训、工资和工时选择；连续两月现金流为负会破产，五年还清一百万债务是长目标。压低员工待遇还是走高成本路线，同时连接人物关系、知识学习和多结局，理论上能让经营数字成为角色伦理的一部分。
- **待验证**：这些参数是否真的产生不同可行路线，而非少数显然最优答案；人物/知识分支与经营系统是否互相影响；每日清洁、查账、投诉等小游戏在长流程里是否重复。发布前不能据商店描述判断系统深度。
- **来源**：[Steam 商店页](https://store.steampowered.com/app/3222890/Taste_of_the_Wind/)（开发发行关系、系统描述、Demo、当前状态）；Steam appdetails API 09:50 快照。
- **历史关系**：此前未出现；与《MarginCall》同为经济系统题材，但不是同一判断，不应强行合并。

### 3. 《Sunset Summit》用频繁检查点改写多人攀登的失败成本，也保留离线单人（简洁）

- **关键事实**：兄弟 Andrew 与 Joe Fender 开发，Future Friends Games 发行；Steam 标注 8 月 21 日发行，09:50 尚未解锁、无正式版评价，Demo 与 Playtest 可用。支持离线单人，在线合作不是进入核心内容的必要条件，暂符合范围。
- **作品方向**：浮空岛路线以攀爬斧、绳索、弹跳杆、补给无人机等工具组织；频繁检查点与立即重生意在把物理攀登从一次失误导致长时间重爬，改成可反复试验的路线挑战。多条手工路线及日落限时可能让“轻松同行”与技术追时并存。
- **待验证**：单人路线是否与 1—8 人协作同样完整；物理稳定性；不同工具是否形成路线选择而不是笑料；检查点是否削弱登顶积累感。若实际体验明显以在线语音协作为唯一核心，应从池中移除。
- **来源**：[Steam 商店页](https://store.steampowered.com/app/3874450/Sunset_Summit/)（团队、离线单人、工具、路线和当前状态）；Steam appdetails API 09:50 快照。
- **历史关系**：此前未出现，是新发现。
