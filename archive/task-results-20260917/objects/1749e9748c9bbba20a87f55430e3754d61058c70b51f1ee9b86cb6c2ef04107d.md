# 亚马逊（AMZN）首次基线复查

- 复查日期：2026-09-01（Asia/Shanghai）
- 研究窗口：2025-09-01 05:30 至 2026-09-01 05:30（+08:00）
- 重点变化窗口：2026-08-02 05:30 至 2026-09-01 05:30（+08:00）
- 选择原因：hard-signal；无历史私有深研记录
- 结论：**有实质变化（yes）**。最近30天最重要的新证据不是沙特区域本身，而是（1）FTC与22州对Amazon Ads的正式诉讼，把监管风险直接推进到高增长、高利润广告变现机制；（2）AWS宣布额外部署200万块NVIDIA GPU，进一步确认AI资本开支仍处在超大规模扩张期。沙特Region按期推进和50MW容量承诺属于正面执行信号，但暂不足以推导收入或回报。

## 一、判断摘要

亚马逊已由“零售规模平台”演化为三台利润引擎叠加：AWS、广告以及效率改善后的零售/第三方服务。2025年收入7,169亿美元、经营利润800亿美元；2026年上半年收入3,821亿美元、经营利润514亿美元，经营杠杆继续改善。AWS在2026Q2同比增长36.7%，为18个季度最快，经营利润166亿美元、利润率约39.3%；广告收入198亿美元，同比增长26%。这些数据确认AI需求和平台广告仍在加速，而非仅靠降本。

但现金流结构明显恶化：截至2026Q2的TTM经营现金流1,614亿美元，而自由现金流为-76亿美元；2026H1现金资本开支963亿美元，同比增加407亿美元，且公司称主要投向技术基础设施、其中多数支持AWS。8月26日新增200万块NVIDIA GPU部署计划使“高增长、高资本强度”成为未来数年的核心矛盾。资本开支若不能转成高利用率的外部收入，折旧、融资和技术迭代将侵蚀当前很强的AWS利润。

8月31日，FTC联合22州正式起诉亚马逊，指控其在广告拍卖中设置未披露的附加费/底价，涉及超过100万广告主，并寻求禁令和金钱救济。这与既有广义反垄断风险不同：它直接触及2025年约686亿美元、2026H1为371亿美元且仍快速增长的广告业务定价机制。因此即便损失金额未定，也足以构成本轮值得公开写作Agent考虑的实质变化。

## 二、公司与行业基线

### 业务结构与护城河

1. **Stores与第三方服务**：北美和国际零售以Prime、履约网络、选择和低价形成规模飞轮；第三方卖家佣金、仓配和支付等服务提高货币化率。2025年北美收入4,263亿美元、经营利润296亿美元；国际收入1,619亿美元、经营利润48亿美元，国际业务已由亏损转为稳定盈利。护城河来自流量、会员、履约密度和卖家供给的相互强化，但受关税、劳动力、物流投入和监管影响。
2. **AWS**：提供计算、存储、数据库、AI与安全等服务。2025年收入1,287亿美元、经营利润456亿美元（利润率35.4%），只占合并收入约18%，却贡献约57%的分部经营利润。2026Q2收入422亿美元、经营利润166亿美元，AI与自研芯片业务各自超过250亿美元年化收入运行率。竞争核心是GPU/自研芯片供给、模型选择、数据驻留、生态和单位算力成本，主要对手为Microsoft Azure和Google Cloud。
3. **广告**：依托购物意图数据、Sponsored Products和Prime Video等库存。2026H1收入371亿美元，Q2同比增长26%。该业务轻资产、与电商交易闭环高度协同，推测其利润率显著高于零售，但公司不单独披露利润。本轮FTC诉讼说明其高货币化率也带来定价透明度与平台权力风险。
4. **其他长期期权**：Amazon Leo卫星网络、Zoox、Pharmacy、Alexa+和供应链服务。当前不宜按成熟利润引擎估值；其价值取决于商业化里程碑，也会消耗资本。

### 财务基线

- 2025年净销售额7,169亿美元，同比增长12.4%；经营利润800亿美元，同比增长16.6%，经营利润率由10.8%升至11.2%。净利润777亿美元，但含Anthropic等投资公允价值影响，不宜直接作为核心盈利基准。
- 2026Q1收入1,815亿美元（+17%），经营利润239亿美元（+30%）；Q2收入2,006亿美元（+20%），经营利润275亿美元（+43%）。北美、国际、AWS三分部Q2经营利润均同比增长。
- 截至2026-06-30，现金及有价证券约1,230亿美元；固定资产净额4,460亿美元，半年增加890亿美元。同期公司通过债务融资并大额投资OpenAI和Anthropic，资产负债表流动性仍强，但资本配置复杂度与非核心估值波动显著上升。
- Anthropic持仓在Q2产生巨额非经营收益；2026Q2净利润626亿美元中包含534亿美元税前其他收益。分析经营趋势时应以经营利润和经营现金流为主，不能将该重估收益年化。

## 三、研究窗口内的重要演变

### 过去一年形成的基线变化

- 2025全年零售利润继续改善，国际分部保持盈利；同时发生FTC Prime案25亿美元和解、裁员/减值等一次性费用，说明效率提升与监管成本并存。
- AWS从2025年收入同比约20%的增速，提升至2026Q1的28%、Q2的36.7%；AI业务和芯片业务均达到250亿美元以上年化运行率，显示增长加速有实际收入支持。
- 资本开支从2024年的777亿美元升至2025年的1,283亿美元；2026H1已达963亿美元。自由现金流随之从正转负，企业价值判断从“利润率修复”转为“AI资本回报能否覆盖资本成本和快速折旧”。
- 亚马逊在2026H1投入OpenAI 287亿美元，并在Q2投入Anthropic 100亿美元；6月后又支付OpenAI剩余承诺213亿美元。商业云合作与权益投资交织，既锁定大客户/模型供给，也带来关联交易、集中度、估值和融资风险。

### 最近30天的新证据

1. **FTC广告诉讼（实质负面变化，2026-08-31）**：FTC与22州在华盛顿西区联邦法院起诉，称亚马逊自2018年以来以未披露方式提高广告拍卖价格，影响逾100万品牌和卖家，并寻求永久禁令、金钱判决及其他救济。事实仅为监管方指控，责任和金额尚未经法院确认；但诉讼对象直接是广告拍卖变现机制，可能带来退款/罚款、拍卖规则调整、广告单价下降及商家关系受损。需将其与2023年广义反垄断案分开追踪。
2. **AWS与NVIDIA扩容（实质战略/资本变化，2026-08-26）**：双方宣布计划在AWS全球基础设施额外部署200万块NVIDIA GPU，并扩展至CPU、网络、模型和物理AI。它强化供给与产品竞争力，但公告没有采购金额、交付节奏、客户承诺或预期利用率，不能据GPU数量直接估算收入。结合H1资本开支，现金流和折旧压力将延续。
3. **DuckLabs收购（普通战略更新，2026-08-26）**：AWS签约收购DuckDB背后的DuckLabs，项目继续MIT开源、基金会继续治理。可补强本地分析数据库与数据生态，但交易金额和商业贡献未披露，不单独构成估值变化。
4. **沙特Region与HUMAIN（正面执行、仍属弱信号，2026-08-31）**：AWS确认沙特首个Region将于2026年12月上线，既有区域计划投资超过53亿美元；与PIF旗下HUMAIN扩大合作，承诺到2028年为首个AI Zone提供最高50MW容量，并提供Trainium和NVIDIA基础设施。应理解为项目进度与主权云/本地AI需求信号，而非53亿美元收入；50MW是容量上限，缺乏利用率、合同期限和收入披露。

## 四、价格与估值

- AMZN 2026-08-28收盘266.43美元，8月下跌约4.3%；8月3日284.02美元至8月28日回落6.2%，但8月28日单日上涨3.97%。这更像高位波动，单日上涨不构成趋势反转。
- 2025-09-02收盘225.34美元，至2026-08-28约上涨18.2%。同期基本面表现为收入和经营利润加速，价格并非明显脱离基本面；最近一个月回撤则发生在强Q2数据之后，体现市场同时计入资本开支压力。
- 以2026-07-22约107.86亿股和266.43美元粗算，股权市值约2.87万亿美元。用2025全年经营利润800亿美元，市值/经营利润约35.9倍；用粗算TTM经营利润约938亿美元（2025全年减2025H1约376亿美元，加2026H1约514亿美元），约30.6倍。该估值要求AWS/广告持续高增长并最终恢复自由现金流，容错率不高。
- 不采用Q2报告净利润计算市盈率，因为Anthropic公允价值重估造成534亿美元税前其他收益。也不把账面Anthropic/OpenAI价值等同于可立即变现现金。

## 五、风险、反证与待验证问题

### 关键风险

- **广告监管**：FTC案可能改变拍卖定价与披露规则，影响广告价格和利润；相关民事索赔也可能跟进。
- **AI资本回报**：GPU/数据中心投入远快于收入，且硬件迭代快、能源与存储供给受限；若利用率或定价不及预期，折旧和现金流压力会先出现。
- **云竞争与客户集中**：AWS增速改善，但OpenAI、Anthropic既是客户/伙伴又是大额被投企业，商业承诺与投资回报需拆分。
- **零售监管与成本**：反垄断、Prime、卖家规则、劳工、关税和物流成本持续存在。
- **非核心资本配置**：卫星、自动驾驶、医疗等长期项目规模大，回报周期和退出路径不确定。

### 会推翻当前偏积极经营判断的证据

- AWS增速连续两个季度明显降至20%以下，同时资本开支仍上升；
- AWS经营利润率因折旧/能源/芯片成本持续跌破30%；
- 广告诉讼导致公司确认重大退款准备、强制改价，或广告增速/货币化率显著下滑；
- TTM自由现金流在2027年仍不能转正，且净债务持续增加；
- 大额AI投资的商业合同不具最低消费承诺，或关联客户出现融资/偿付压力。

### 下一轮明确跟踪

1. FTC广告案：案号、Amazon答辩、禁令范围、损害金额方法、是否出现广告主集体诉讼；重点区分指控与司法认定。
2. 2026Q3/Q4：AWS收入增速、经营利润率、广告增速，以及Q3指引收入1,970亿—2,020亿美元、经营利润225亿—265亿美元的兑现程度。
3. 资本开支：季度现金资本开支、融资租赁、折旧增速、GPU交付进度、利用率或客户承诺；核验200万GPU是否为净新增及时间表。
4. 沙特：12月Region是否按期上线、首批客户和可用区、HUMAIN 50MW的建设/投产节奏及是否披露最低采购承诺。
5. AI权益投资：OpenAI/Anthropic商业合同、云消费与股权投资现金流分拆，避免将投资重估计入核心EPS。
6. 价格：若基本面保持当前增速但股价持续跌破Q2前水平，检查资本开支、监管或竞争是否已形成基本面先行信号。
