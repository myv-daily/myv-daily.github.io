## 结论

本轮存在值得公开写作 Agent 考虑的实质变化，但实质变化来自收市后完成的产品承诺，而不是 6.03% 的普通回撤。Hugging Face 官方仓库显示，GLM-5.3 原版权重于 8 月 28 日 23:22（北京时间）更新并已公开、无需申请访问；仓库列出 141 个 FP8 safetensors 分片，索引总大小约 755.6GB，并提供配置、tokenizer、部署说明和许可证。这兑现了 8 月 14 日“约两周后公开”的承诺，也补完了上一轮明确留下的核心验证点。至此，8 月 26 日的低成本原生多模态 GLM-5.3-Flash 与旗舰 GLM-5.3 均有可下载权重，公司的开放模型产品层次更完整。

许可边界比此前对“open-weights”的笼统理解更严格。GLM-5.3 不是 MIT 许可；自定义许可证允许使用、修改、分发、部署和商业化，但若被许可方或关联方经营模型即服务业务、连续 12 个月合计收入超过 100 亿美元，商业使用前须通过 Z.AI 安全审查。该门槛对多数开发者没有即时影响，却可能影响大型云厂商或头部模型服务商的采用决策，不能把这次开放表述为“无条件开源”。仓库在截止时下载计数仍为 0，且尚无新增调用、客户、收入或毛利数据，因此交付可信度可以上调，商业化与盈利预测仍不能上调。

价格信号反而降温。8 月 28 日智谱由 1,160 港元跌至 1,090 港元，收盘跌回上一轮 1,129 港元验证位以下 3.45%，且明显跑输恒生科技指数和 MiniMax；但成交量仅为前一日 56.4%，收盘仍比 8 月 26 日高 5.83%，也没有重新测试 1,000 港元。应把“放量突破后的初步趋势修复”下调为“突破确认失败、仍处高波动区间”，而不是直接判断趋势反转。更重要的是，GLM-5.3 仓库更新时间在港股收市后约七小时，8 月 28 日行情不可能是对原版权重开放的市场反应；下一交易日才是这一增量证据的首次价格验证。

## 本轮增量事实与判断

### 1. GLM-5.3 原版权重按期公开，历史待验证问题完成

- Hugging Face API 在本轮核验时显示 `zai-org/GLM-5.3` 仓库为公开、非 gated、未禁用，最近更新时间为 2026-08-28 15:22:14 UTC，即北京时间 23:22:14，严格位于本轮截止时点之前。
- 仓库不是只有模型卡的占位页。文件列表包括 141 个 `safetensors` 权重分片、权重索引、配置、tokenizer、chat template、评测结果和许可证；权重索引标示总大小 755,617,140,416 字节，约 755.6GB。配置显示 FP8 量化、78 层、1,048,576 最大位置长度和每 token 选择 8 个专家，与旗舰模型的大规模本地部署定位相符。
- 模型卡列出 Transformers、SGLang、vLLM、TokenSpeed、KTransformers、Unsloth 以及昇腾 NPU 部署路径。这证明公司不仅给出权重文件，也提供了初步部署入口；但本轮没有实际下载并运行约 756GB 权重，不能独立验证文件可完整加载、吞吐、稳定性或评测成绩。
- 8 月 14 日发布页仍保留“约两周后公开”的文字，而仓库在 8 月 28 日晚完成更新，时间上基本按期。上一轮“GLM-5.3-Flash 已开放、GLM-5.3 原版仍待开放”的区分现已消失；模型交付节奏判断进一步改善。
- 截止时 API 显示下载量为 0，这与刚刚发布的时点一致，也说明尚无采用数据。点赞数、模型卡评测和公司自报成绩不能替代真实部署或客户付费证据。

### 2. 自定义许可证新增大型 MaaS 使用边界，不等同 MIT

- 仓库标签为 `license:other`，许可证名称为 GLM-5.3。正文允许免费使用、复制、修改、合并、发布、分发、再许可、销售、部署、微调及创建衍生作品，整体开放度较高。
- 额外条件是：若使用者或关联方经营“模型即服务”业务，且任意连续 12 个月合计收入超过 100 亿美元，使用该模型或衍生作品进行商业用途前必须通过 Z.AI 安全审查。许可证把 MaaS 定义为允许第三方对输入、参数或训练数据实施实质控制的推理或微调服务，并排除仅嵌入特定功能的终端产品和简单转发。
- 这与 GLM-5.3-Flash 仓库标示的 MIT 许可不同。对于普通研究者和多数企业开发者，限制短期不构成主要障碍；对于大型云厂商、海外头部 AI 平台或其关联集团，条件可能增加法务和采用摩擦。它既可能保护安全边界和公司的商业利益，也会降低“完全无附加条件开放”带来的生态扩散速度。
- 许可证并未披露安全审查标准、周期或拒绝条件，因此不能估算对潜在合作方的实际影响。后续若大型云平台正式托管 GLM-5.3，可作为该边界未妨碍分发的验证。

## 对历史待验证问题的进展

1. **GLM-5.3 原版权重开放**：完成。公开、非 gated 仓库已有 141 个权重分片和完整索引，更新时间落在承诺的两周期限附近。
2. **许可与安全边界**：取得关键进展。GLM-5.3 使用自定义许可而非 MIT，并对收入超过 100 亿美元的 MaaS 经营者设置安全审查条件；审查标准和实际影响仍待观察。
3. **1,129 港元支撑与价格趋势**：负面进展。8 月 28 日即跌回 1,129 以下，前一日突破未确认；但缩量且两日累计仍上涨，尚未形成新的下跌趋势确认。
4. **模型竞争位置与独立复现**：开放为第三方复现创造条件，但截止时下载计数为 0，尚无新增独立成绩。
5. **API 调用、付费留存和单位经济**：无进展。权重交付不证明托管服务调用或毛利改善，也可能产生 API 分流。
6. **国产算力适配**：模型卡提供昇腾 NPU 部署入口，但缺实际吞吐、稳定性、硬件规格和成本数据，仍只是可部署路径而非经济性验证。
7. **中期业绩、ARR、配售款、1GW 数据中心与科创板发行**：无新增正式进展。

## 风险与后续观察

价格上，下一交易日是市场首次消化 GLM-5.3 原版权重开放的时点。若重新收复 1,129 港元并在 1,160—1,171 港元上方站稳，8 月 28 日可视为事件间的缩量回踩；若继续跌破 1,063—1,030 港元，再测试 1,000 港元，则 8 月 27 日更接近一次短促发布行情。需同步比较 MiniMax 和恒生科技指数，避免把板块共振误作公司独有信号。

基本面上，首要观察第三方能否实际加载约 756GB FP8 权重并复现性能，主流推理框架和国产芯片的吞吐、稳定性及显存需求，以及大型云平台是否在自定义许可下提供托管服务。商业验证仍应优先看 API 调用结构、Coding Plan 付费与留存、私有化部署订单、推理成本和毛利，而不是下载或点赞。还应关注开放旗舰与低成本 Flash 是否扩大整体生态，或对公司收费 API 形成内部替代。

本轮应标记为“有实质变化”。理由是上一轮明确未完成的旗舰权重承诺已在截止前实质交付，并出现有判断价值的许可边界；6.03% 回撤本身只使价格判断降温，不单独构成公开价值。公开表述应明确：权重在收市后才开放，所以当日下跌不是市场对此的反应；许可证也不是 MIT，商业采用和经营贡献均未验证。由于下一个交易日将首次反映新事件，且中期业绩与第三方复现仍可能提供硬证据，不宜机械等待 2026-09-22；建议在下一交易日出现显著价格确认、首批独立部署结果或正式经营披露时提前复查。
