# 招商银行（cn-600036）增量复查｜2026-08-30

## 本轮结论

本轮覆盖 2026-08-16 05:30:17 至 2026-08-30 05:30:16。2026-08-28 晚间披露的半年报提供了上轮缺失的正式经营证据，判断为 **有值得公开写作 Agent 考虑的实质变化（material change = yes）**，但变化不是单向利好：上半年营业收入1,781.81亿元、归母净利润764.45亿元，分别同比增长4.83%、2.02%，收入增速较一季度的3.81%继续改善；净利息收入和净手续费收入同时恢复，证明低成本负债与大财富管理仍能缓冲资产端降价。与此同时，二季度净息差仍环比下行，零售贷款余额收缩而不良率、关注率、逾期和不良生成上升，信用减值损失增速显著快于收入，拨备覆盖率继续下降。

最重要的结构变化是“财富管理修复、批发盈利上行、零售信贷承压”同时发生。零售仍贡献54.34%的营收，但零售税前利润同比下降17.58%至428.88亿元，已低于批发金融457.03亿元（同比增长23.33%）。因此不能把财富管理收入增长直接等同于零售银行整体盈利能力回升；当前改善主要由负债成本下降、对公扩张和财富中收共同支撑，而零售信用成本正在吞噬部分成果。

## 相对上次深研的新证据

### 1. 收入恢复得到确认，但利润弹性被减值与ROE下滑约束

上半年营业收入同比增长4.83%，归母净利润增长2.02%，扣非归母净利润增长2.03%。净利息收入1,120.22亿元，同比增长5.60%；净手续费及佣金收入398.55亿元，同比增长5.99%；成本收入比29.70%，同比下降0.41个百分点。收入端比上轮只有一季报时更具确认度。

但信用减值损失291.77亿元，同比增长18.49%，其中贷款减值254.63亿元，同比增加21.22亿元，主要受对公贷款规模上升及零售贷款资产质量变动影响；表外项目减值37.08亿元，同比增加22.62亿元。ROAA为1.14%，同比下降0.07个百分点，ROAE为13.42%，同比下降0.43个百分点。收入恢复尚未转化为回报率拐点，利润增速低于营收并非偶然。

### 2. 息差降幅收窄，但二季度仍未见底

上半年净息差1.83%，同比下降5个基点；净利差1.77%，同比下降2个基点。生息资产收益率同比下降32个基点至2.82%，计息负债成本率下降30个基点至1.05%，负债端几乎抵消资产端降价。客户存款平均成本率由去年同期1.26%降至0.97%，其中公司存款由1.33%降至1.02%、零售存款由1.18%降至0.91%，是净利息收入增长的核心来源。

季度拆分仍偏谨慎：二季度净息差1.82%，环比下降1个基点；净利差1.75%，环比下降2个基点。贷款平均收益率由一季度3.13%降至3.10%，客户存款成本由0.99%降至0.95%。因此“同比降幅收窄”成立，“息差见底”尚不成立。管理层预计下半年降幅可能进一步收窄，但也明确有效资产投放和活期存款高基数限制改善空间，应作为前瞻判断而非事实。

### 3. 财富管理是真修复，但零售整体利润并未修复

大财富管理收入247.04亿元，同比增长18.44%；财富管理手续费及佣金收入161.92亿元，同比增长26.53%。代理非货币公募基金销售额4,867.61亿元，同比增长82.73%，代理信托销售额1,290.15亿元，同比增长40.48%；零售AUM达到18.44万亿元，较年末增长7.96%，财富产品持仓客户数增长4.05%。托管佣金同比增长20.52%，但资产管理手续费同比下降1.52%，银行卡手续费同比下降11.73%，传统银行卡收费压力延续。

零售金融营业收入968.20亿元，仅同比增长0.65%；其中零售净利息收入同比下降3.23%，零售税前利润同比下降17.58%。批发金融营业收入755.36亿元，同比增长7.42%，净利息收入同比增长21.69%，税前利润同比增长23.33%。这说明财富管理修复有交易量、AUM和客户基础支撑，并非纯会计波动，但其贡献暂时不足以抵消零售利息收入与信用成本压力。对公贷款较年末增长9.08%，明显快于集团贷款2.69%，业务重心阶段性向批发倾斜。

### 4. 总体不良率稳定掩盖零售风险进一步上行

集团不良贷款率0.94%，与年末持平，但不良余额增加20.45亿元至702.51亿元；关注类贷款率由1.43%升至1.53%，关注类余额增加102.34亿元；逾期贷款973.40亿元，较年末增加67.02亿元，逾期率由1.25%升至1.31%。上半年新生成不良371.86亿元，同比增加44.65亿元，不良生成率1.06%，同比上升8个基点；信用成本0.69%，同比上升2个基点。拨备覆盖率由391.79%降至385.10%，贷款拨备率由3.68%降至3.63%。绝对缓冲仍厚，但前瞻指标和拨备方向均不支持“资产质量改善”。

风险分化十分明显。公司贷款不良率由0.89%降至0.78%，不良余额减少12.03亿元；房地产业贷款不良率也由4.78%降至4.47%。零售贷款余额较年末下降1.08%，不良余额却增加32.48亿元，零售不良率由1.06%升至1.16%。其中小微贷款不良率1.34%（年末1.22%）、信用卡1.90%（1.74%）、消费贷款1.39%（1.02%），个人住房贷款则由0.51%改善至0.48%。信用卡新生成不良236.98亿元，同比增加39.29亿元，是当前最主要的不良来源。承担信用风险的房地产相关业务余额3,592.09亿元，较年末增长1.48%，风险率改善但敞口未明显收缩，仍需持续跟踪。

### 5. 资本缓冲仍足，核心一级资本随扩表略降；中期分红金额尚未落地

高级法核心一级资本充足率14.07%，较年末下降0.09个百分点；一级资本和资本充足率分别为16.59%、18.33%，各上升0.08和0.09个百分点。风险加权资产较年末增长5.16%，核心一级资本净额增长4.47%，解释了核心一级资本率的小幅下降。资本仍显著高于监管要求，但“扩表快于核心资本积累”的观察点继续成立。

半年报仅说明2026年度中期利润分配计划已获2025年度股东会授权，将由董事会后续具体实施，现金分红时间为2027年1月至2月；本轮尚无每股金额或总额，不能把“拟分红”当作新增股东回报提升。

## 判断更新、反证与下一轮验证点

1. **盈利判断上调但不判拐点。** 从“只有一季报的初步恢复”上调为“半年收入恢复已确认”；若三季度净利息与手续费继续双增且信用减值增速回落，才可进一步上调利润质量。若减值继续快于营收，收入修复对股东回报的意义应下调。
2. **息差仍是首要验证项。** 下轮拆分三季度贷款收益率、存款成本和单季NIM。只有单季NIM持平或回升，才能确认负债降成本越过资产重定价压力；管理层的“降幅收窄”预期不能替代结果。
3. **零售信贷升级为最重要风险线索。** 重点跟踪信用卡、消费贷和小微的不良生成、关注/逾期、核销及拨备。若零售余额继续收缩而不良率继续升，说明风险并非仅由规模口径造成；若新生成明显下降且早期逾期回落，才可能确认压力见顶。
4. **财富管理需区分量价与市场β。** 跟踪AUM净流入、持仓客户、代销结构和费率，验证基金/信托高增能否跨季度持续；同时关注银行卡手续费下降是否继续抵消部分中收修复。
5. **批发增长的质量。** 对公贷款上半年增长9.08%，明显快于年度6%—7%左右计划节奏。需观察三季度增速、收益率、行业集中度与表外减值，防止低价扩量或风险滞后；对公不良率下降是正面反证。
6. **房地产风险并未消失。** 房地产不良率改善，但承担信用风险敞口增加。继续追踪新增投放、重组/展期、关注类和项目现金流，不能仅据不良率下降判定风险出清。
7. **资本与分红。** 等待董事会确定2026年度中期每股分红金额，结合核心一级资本率和风险加权资产增速判断分红可持续性。
8. **管理层执行。** 本轮未见王小青上任后新增的组织、风险偏好或资本配置重大调整；半年报战略仍延续客户中心、财富管理、资产质量和AI First。下一轮继续观察量化目标与具体人事/考核变化。
