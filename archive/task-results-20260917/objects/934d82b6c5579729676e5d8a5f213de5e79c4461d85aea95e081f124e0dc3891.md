# 智谱（02513.HK）增量复查

复查日期：2026-08-18；研究窗口：2026-08-14 05:30:17 至 2026-08-18 05:30:17（北京时间）；选择原因为行情硬信号：2026-08-17 16:08:37 单日下跌 5.28%。本次承接 2026-08-14 私有深研，只判断该时点之后的新证据。

## 结论

本轮发现值得公开写作 Agent 考虑的实质变化，核心不是 5.28% 的下跌，而是智谱在上一轮截止约 8.5 小时后正式发布 GLM-5.3。新模型与 GLM-5.2 使用相同基座，主要依靠更大规模后训练，在多项编程、长程 Agent 和网络安全测试中显著提高。它已于发布日起进入 ZCode、AutoClaw、GLM Coding Plan 全量用户及多个第三方编码平台，说明技术迭代已进入可用产品，而非仅有预告。

这项证据提高了对智谱“保持前沿模型快速迭代、用后训练释放既有基座能力”这一技术判断的信心，也为 Coding Plan 的续费、提价和开发者获客提供了潜在新催化。但它尚未改变财务和估值中心判断：公司称 API 将很快上线，模型权重需在安全评估和加固后两周内开放；截至窗口结束未披露新模型 API 定价、付费用户增量、调用量、推理成本或收入贡献。发布后的首个完整交易日股价反而下跌 5.28%，说明市场没有把模型更新直接定价为已兑现商业价值，也再次体现该股高波动和事件交易特征。

因此，本轮应把 GLM-5.3 记为“实质产品与竞争力变化”，但不能上调为“商业化或估值已验证”。此前对 10 亿美元 ARR 口径、推理毛利、现金消耗和极高估值的谨慎判断不变。

## 本轮增量事实与判断

### 1. GLM-5.3 发布：技术迭代构成实质变化

- 公司官网记录的发布时间为 2026-08-14 14:00（页面后台时间 2026-08-14T06:00:00Z），明确晚于上轮研究截止 05:30:17，因此属于本轮新增事件。
- 公司称 GLM-5.3 与 GLM-5.2 基座相同，提升全部来自后训练 Scaling，包括数十倍的长程任务环境、更丰富环境类型和更长后训练时间。这意味着模型迭代未必需要同步扩大基座预训练规模，若结论可重复，可能改善研发迭代速度与既有训练资产复用效率；但公司没有披露后训练算力、成本或单位性能提升成本，不能据此推定毛利改善。
- 公司披露 Terminal-Bench 3.0 得分由 4.6 升至 28.3，DeepSWE v1.1 由 46.2 升至 66.9，Agents' Last Exam 由 23.8 升至 28.5；内部 Z.ai Code Bench 的 High 档准确率为 31.4%，公司称高于 Claude Opus 4.8 最高档的 29.5%，且平均输出 Token 更少。公开基准与内部体感测试共同指向编程和长程执行能力提升，但跨模型比较的运行配置、预算和公司自测偏差仍需第三方复现。
- 新模型当天已进入 ZCode、AutoClaw、GLM Coding Plan 全量用户及 Trae、扣子、腾讯 CodeBuddy、阿里 Qoder 等平台的抢先体验。这比单纯模型榜单更接近产品分发证据，但“可使用”仍不等同于新增付费、留存或收入。

### 2. 网络安全能力成为新产品机会，也新增治理风险

- 公司披露 GLM-5.3 在 CyberGym 得分 84.5%，高于 GLM-5.2 的 77.2%；ExploitBench 得分 54.4%，较前代 24.4%翻倍以上，但仍低于公司列示的前沿闭源模型。ExploitGym 两小时和六小时任务完成数分别由前代 29/39 项提高至 105/130 项。
- 公司因此决定延后模型权重开放两周，先完成安全评估和加固，并向选定安全伙伴提供受控访问。Axios 在 8 月 14 日报道并交叉确认这一安排，还提到公司推出面向开源维护者的漏洞扫描项目。
- 投资含义是双向的：安全代码审计可能扩展企业付费场景并形成技术差异化；另一方面，模型权重延期说明能力已接近需要额外治理的门槛，未来开源后的滥用、出口或平台限制、网络安全监管和声誉风险均上升。当前没有订单或付费数据，机会和风险都不应量化进收入预测。

### 3. 行情：发布后的下跌不构成基本面反转，但形成价格—产品分化

- 任务行情快照显示，2026-08-17 16:08:37 单日下跌 5.28%。该日是 GLM-5.3 发布后的首个完整交易日（8 月 15—16 日为周末）。
- 上一轮触发为 8 月 13 日上涨 9.02%，且最近 5 个采样点累计仅上涨 9.84%。若只机械复合这两个已知单日变化，价格仍较 8 月 12 日收盘附近高约 3.26%；由于缺少 8 月 14 日精确涨跌，不能把这个数当作完整窗口累计收益，但足以说明 8 月 17 日下跌更像前次脉冲的部分回吐，而不是已确认趋势反转。
- 新模型发布后股价未延续上涨，不能证明模型失败；更合理的解释是技术新闻尚不足以克服估值、流动性和兑现不确定性。任务未提供成交量、换手率或恒生科技指数同期数据，因此不判断是否存在放量出货或行业共振。
