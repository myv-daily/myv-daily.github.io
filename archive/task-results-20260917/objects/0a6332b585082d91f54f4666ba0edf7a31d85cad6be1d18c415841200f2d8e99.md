# 智谱（02513.HK）增量复查

复查日期：2026-08-22；研究窗口：2026-08-19 05:30:16 至 2026-08-22 05:30:17（北京时间）；选择原因为行情硬信号：2026-08-21 16:08:14 单日上涨 10.36%，最近 5 个采样点累计下跌 11.10%。本次承接 2026-08-19 私有深研，只判断该时点之后的新证据。

## 结论

本轮发现值得公开写作 Agent 考虑的实质变化。基本面层面，上一轮最关键的待验证事项之一已经部分落地：智谱于 8 月 19 日正式开放 GLM-5.3 按量 API，定价与 GLM-5.2 保持一致，即国内公开目录价每百万 Token 输入 8 元、输出 28 元、缓存命中 2 元。模型从 Coding Plan 和第三方平台体验扩展到可程序化、按量付费调用，商业化入口由“即将上线”变成可用产品；但价格没有上调，尚无调用量、付费客户、留存、单位推理成本或收入贡献数据，因此只能确认可售性改善，不能确认收入兑现。

价格层面，上一轮连续放量急跌后的弱势暂时被打断，但尚未反转。智谱 8 月 19 日跌 2.97%、20 日涨 1.09%、21 日涨 10.36%至 1,129 港元；相对 8 月 18 日收盘累计反弹 8.25%，但仍较 8 月 14 日收盘低 11.10%、较 8 月 14 日日内高点低 21.3%。8 月 21 日成交 881.7 万股、成交额约 94.43 亿港元，明显高于 19—20 日，且收盘接近日内高点，显示资金重新追逐大模型板块和指数预期。当天 MiniMax 同涨 11.86%，恒生科技指数涨 1.40%，因此这不是智谱独有的基本面重估。

需要特别注意时点错位：市场在 8 月 21 日收盘前交易智谱及 MiniMax 可能纳入恒生指数的预期，但盘后正式检讨结果并未将两者纳入恒生指数；实际新增的是华虹宏力和潍柴动力，恒生科技指数新增天数智芯。落选发生在本研究窗口内但尚未经过下一个交易日定价，构成下一交易日的潜在预期回吐风险。故本轮最稳妥的综合判断是：API 落地消除了一个产品可用性不确定性，价格也出现板块性技术修复，但商业化结果仍无证据，且指数落选可能令反弹承压。

## 本轮增量事实与判断

### 1. GLM-5.3 API 正式上线，商业化入口从待定转为可调用

- 8 月 19 日 09:14 的公开消息确认，GLM-5.3 API 即日起正式上线，模型已开放调用，纳入 GLM Coding Plan，并接入 ZCode 等编码平台；模型权重计划于下一周五开放。该事件发生在上一轮截止后，是明确的新信息。
- GLM-5.3 国内按量价格沿用 GLM-5.2：每百万 Token 输入 8 元、输出 28 元、缓存命中 2 元，缓存存储限时免费。海外公开口径为每百万 Token 输入 1.40 美元、输出 4.40 美元、缓存输入 0.26 美元。价格不变意味着智谱选择用性能升级维持现价，而不是借新模型再次提价。
- 文档所示产品规格包括 100 万 Token 上下文、最高 12.8 万 Token 输出、强制推理并可选 low/high/max 推理强度，支持 OpenAI Chat Completion、OpenAI Response 和 Anthropic Message 兼容协议。这提高了迁移和集成的可操作性，但强制推理也可能影响时延及实际输出成本，需用真实工作负载验证。
- 8 月 20 日行业报道补充称，原计划 8 月 18 日上线的 API 曾短暂推迟，销售收到客户询问和算力锁定需求。该说法来自媒体采访而非公司正式经营披露，只能作为需求线索；最终延迟约一天且已经上线，不足以判断交付能力恶化。
- 对历史判断的修正是明确但有限的：上一轮“模型发布暂时没有 API 商业化证据承接”不再成立；现在已经有可计价、可调用的商品。但“客户热情”不是收入，沿用旧价也不等于单位经济改善。下一步应把问题从“何时上线、如何定价”更新为“调用量、付费转化、客户留存、峰值可用性和毛利贡献”。

### 2. 8 月 21 日放量反弹打断连续下跌，但主要呈现板块与事件交易特征

- 8 月 19 日智谱收报 1,012 港元，较 1,043 港元跌 2.97%，最低 983 港元，连续第三日下跌；成交量降至 440.8 万股，约为 18 日的 41%。20 日收报 1,023 港元，涨 1.09%，成交进一步降至 323.7 万股，初步止跌但力度很弱。
- 21 日开盘 1,016 港元，最低 992.5 港元，最高 1,149 港元，收报 1,129 港元，单日上涨 10.36%；成交 881.7 万股、成交额约 94.43 亿港元。成交量约为前两日均量的 2.31 倍，收盘仅比日内高点低 1.74%，属于放量、收近高位的显著修复。
- 从上一轮急跌后的 8 月 18 日收盘计算，三日累计反弹约 8.25%；但从 GLM-5.3 发布日 8 月 14 日收盘计算仍跌 11.10%，从当天 1,435 港元高点计算仍低 21.3%。因此“连续下跌”已被打断，“短期弱势已完全逆转”尚无依据。
- 同日 MiniMax 上涨 11.86%，恒生科技指数上涨 1.40%；智谱跑赢大盘约 8.96 个百分点，却略跑输直接同业 1.50 个百分点。大模型双雄同步放量反弹，支持板块性风险偏好和共同事件预期解释，而不是智谱 API 上线单独驱动。
- 8 月 19—21 日智谱收盘累计涨 8.25%，MiniMax同期从 318.8 港元升至 347.2 港元、累计涨约 8.91%，走势高度接近。价格与同业重新同步，上一轮智谱相对 MiniMax 异常弱势有所收敛。

### 3. 恒指纳入预期盘后落空，反弹存在尚未定价的事件风险

- 8 月 21 日盘中公开市场持续讨论智谱与 MiniMax 可能进入恒生指数；当日两股分别上涨 10.36%和 11.86%，具备明显的共同事件交易特征。不能证明全部涨幅都来自该预期，但时间与横截面表现一致。
- 8 月 21 日收盘后公布的 2026 年二季度恒生指数系列检讨结果显示，恒生指数新增华虹宏力、潍柴动力，恒生科技指数新增天数智芯，智谱和 MiniMax 均未获纳入恒生指数。正式调整将于 9 月 7 日生效。
- 智谱原已是恒生科技指数成份股，本轮落空的是更广泛的恒生指数纳入预期，不改变其现有恒生科技指数地位，也不改变既有港股通资格。但预期落空意味着此前假设的新增恒指被动资金不再成立。
- 该结果在周五盘后出现，研究截止前没有后续港股交易可观察。因此不能把 21 日反弹当成市场已经消化落选后的有效价格；8 月 24 日开盘后的相对表现与成交将是最优先验证点。

### 4. 公司披露、财务与长期判断没有同步变化

- 港交所发行人披露检索截至本轮截止仍以 8 月 4 日的 7 月证券变动月报为最新文件；未见窗口内新增业绩、盈利预警、融资、重大客户、股权变化、管理层或监管公告。公司投资者关系页也未显示新的定期财务报告。
- 2025 年收入 7.24 亿元、经调整亏损 31.82 亿元、毛利率约 41%，以及 7 月配售净募资约 313.75 亿港元的基线不变。本轮 API 上线没有足够数据调整收入、毛利、现金消耗或估值模型。
- 以 8 月 21 日收盘价计，行情源显示总市值约 5,256.9 亿港元。公司仍亏损，市盈率不是有效估值锚；即使较 6 月高点大幅回撤，绝对估值仍依赖高速增长和商业化兑现，不能因三日反弹或 API 可用就判定估值合理。

## 对历史待验证问题的进展

1. **模型竞争位置**：无独立复现新证据。公司自报性能仍需第三方统一环境验证。
2. **付费调用与留存**：API 已开放，问题由“是否可调用”进入“调用量和转化率”阶段；仍无用户、调用、续费或收入数据。
3. **API 与定价**：取得实质进展。正式按量 API 已上线，国内价格为输入 8 元、输出 28 元、缓存命中 2 元/百万 Token，与 GLM-5.2 一致；下一步核验限速、稳定性、真实时延和客户迁移。
4. **中期业绩与 ARR 口径**：无进展。10 亿美元 ARR 仍未由正式财务披露定义或核验。
5. **毛利与研发杠杆**：无直接进展。沿用旧价且强制推理，收入单价可知但平均推理成本未知，无法判断单位 Token 毛利。
6. **配售款与 1GW 数据中心**：无新增正式进展。资金用途、投运容量、所有权与经济性仍待验证。
7. **科创板发行**：无新增进展。
8. **安全与监管**：权重仍计划在安全评估和加固后于约 8 月 28 日开放；API 消息称下一周五开源，与原计划一致，尚未实际完成。
9. **急跌原因与持仓结构**：价格相对 MiniMax 的异常弱势已在本轮收敛，但没有股东供给、沽空或持仓证据解释上一轮急跌。8 月 21 日南向成交额很高，但成交额不是净买入，不能据此判断北水方向。
10. **指数事件**：新增待验证问题。恒指纳入预期已落空，观察 8 月 24 日是否出现预期回吐，以及市场能否以 API 商业化和板块情绪承接。

## 风险与后续观察

下一轮优先观察 8 月 24 日智谱和 MiniMax 对恒指落选的价格反应，比较两者与恒生科技指数的相对强弱、成交量及南向净买卖；若反弹迅速回吐，21 日更接近指数预期和板块交易，而非基本面重估。若落选后仍能维持 1,100 港元附近并继续放量走强，API 上线和模型商业化预期的解释权重可提高。

基本面观察顺序更新为：GLM-5.3 API 调用量、付费客户与服务稳定性；权重能否按约于 8 月 28 日开源及安全限制；第三方基准和实际编程任务复现；中期业绩对 ARR、API 收入、毛利和现金消耗的正式披露；配售资金和算力基础设施进展。尤其要区分 API “已上线”与“形成可观收入”，也要区分目录价格与折扣后的实际成交价。

本轮 API 正式商业化与价格公布改变了上一轮待验证状态，属于值得公开写作 Agent 考虑的实质变化；8 月 21 日放量反弹及盘后恒指落选则构成重要的价格与风险补充。公开表达应避免把单日反弹写成趋势反转，也不应把盘中涨幅全部归因于 API 或指数预期。

下次可维持原定最晚 2026-09-13；但若 8 月 24 日因指数落选出现显著异动、约 8 月 28 日权重开放延期或附带重大安全限制、公司发布中期业绩或披露 API 经营数据，应提前复查。
