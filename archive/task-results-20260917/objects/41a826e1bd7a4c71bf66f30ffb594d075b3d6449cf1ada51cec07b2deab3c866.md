# 贝壳（BEKE / 02423）增量复查：政策托底增强，但财报后溢价已基本回吐

## 复查结论

复查日期为2026年9月1日，增量窗口为2026年8月22日05:30至9月1日05:30（北京时间），起点接续8月22日首次深研。本轮结论为：**没有足以再次上调公司盈利中枢的新增经营证据，但行业政策出现值得后续公开写作 Agent 考虑的实质变化，因此提交时标记为“有实质变化”**。

8月28日，房地产融资、现房销售和资本市场支持政策同时落地。对贝壳而言，开发贷款按项目而非单纯主体信用管理、支持开发商再融资和并购，边际降低新房佣金回款与项目烂尾风险；逐步转向现房销售则提高交付确定性，却也可能拉长开发商销售和回款周期，并改变新房渠道佣金的结算节奏。政策改变的是风险分布和中期行业制度，不是已经兑现的成交反转。截至窗口末没有贝壳新的经营数据，也不能用政策标题替代GTV、回款或信用损失的验证。

本轮硬信号来自8月31日BEKE单日下跌约6.1%。它发生在财报后上涨和8月28日放量上涨之后，窗口末17.20美元已经低于8月21日财报后17.75美元收盘，仅比财报前16.99美元高约1.2%。没有同期公司负面公告；更合理的解释是盈利重估交易的短期回吐，而不是基本面突然恶化。价格对二季度利润率跃升的溢价很快消失，令“盈利改善与估值反应不足”的偏离略有扩大，但单日波动本身不构成新的趋势反转。

## 上次判断与本轮需要验证的问题

上次研究已建立完整基线：二季度GTV同比增长6.3%、收入下降5.7%，但四条主要业务贡献率同步改善，调整后经营利润率由6.2%升至14.6%；这把贝壳从“利润主要随楼市成交波动”修正为“平台化、组织优化和新业务单位经济改善可以在弱楼市中抬高盈利”。同时，全国新房销售仍弱，MAU、活跃经纪人和活跃门店下降，家装主动缩量，租赁利润率含净额确认迁移，三季度淡季才是利润率持续性的关键检验。

本轮距离财报仅10天，预期本就不应出现新的季度经营验证。重点转为：公司是否补充电话会或公告信息、房地产政策是否改变行业风险、以及财报后价格反应是否形成持续重估。检索公司IR、SEC 6-K和港交所公告后，窗口内新增公司文件主要是8月24日将二季度新闻稿及中期业绩公告提交6-K；其内容没有改变8月22日已经研究的数字和判断。未发现新的回购披露、重大管理层变化、经营月报或业务事件。

## 增量事件一：房地产支持政策从需求端扩展到融资与销售制度

### 事实与事件时间

2026年8月28日，中国人民银行与国家金融监督管理总局发布《关于改革完善房地产信贷管理 推动加快构建房地产发展新模式的意见》。公开说明显示，房地产开发贷款将更重视项目本身，匹配项目建设和销售周期，目标包括满足合理融资需求和保护购房人权益。同日，中国证监会发布资本市场支持房地产新模式的意见，支持上市开发企业再融资、以股份/可转债/现金收购涉房资产，并扩大公司债、CMBS和ABS等融资支持。住房销售制度亦要求新供地和未获规划许可项目优先采用现房销售，已有许可项目被鼓励跟进。

这是同一天落地的制度组合，不是8月31日股价下跌之后的事后消息。政策出台日BEKE上涨3.33%、成交1411万股，约为其近期日均成交量的三至四倍；但不能据此断言上涨完全由政策驱动，因为市场仍在消化一周前的强劲二季度利润，且同期有分析师上调目标价和期权交易热度。

### 对贝壳的传导

1. **新房回款和信用损失风险边际改善。** 贝壳新房佣金最终依赖开发商项目销售和现金回款。开发贷款从过度依赖主体信用转向项目评估、支持优质项目和开发商资本补充，若执行有效，应降低部分项目停工和佣金应收恶化概率。这与上次记录中“二季度已有主要为非经常性的信用损失拨备”的风险直接相关。
2. **现房销售提高消费者信任，但现金周期可能后移。** 现房减少预售交付风险，长期可能改善购房意愿和服务质量，也利于贝壳筛选可交付项目；另一方面，开发商要承担更长建设期资金占用，成交确认、渠道佣金结算和项目供给节奏可能后移。贝壳的新房GTV和佣金收入未必立即受益。
3. **行业结构更有利于综合服务平台，但并非没有成本。** 从预售、高杠杆开发转向现房和项目制融资，会提高开发商资金与运营门槛，行业可能进一步集中于信用较好、交付能力强的项目。贝壳的项目筛选、跨品牌经纪网络和一二手联动能力具有相对价值；但若开发商为覆盖融资成本压缩渠道费率，贝壳新房贡献率仍可能承压。

因此，本轮应把“开发商信用与回款风险持续恶化”从单向风险修正为“政策开始提供更直接的项目融资缓冲，但执行和佣金现金周期尚未验证”。不能上调行业需求基线，也不能据此年化二季度14.6%的调整后经营利润率。

## 增量事件二：硬信号是财报后交易回吐，不是新基本面证伪

BEKE在8月21日财报日从16.99美元升至17.75美元。增量窗口内，8月24日至27日收盘分别为17.71、18.01、17.87和17.73美元；8月28日放量上涨3.33%至18.32美元；8月31日下跌6.11%至17.20美元，成交419万股。8月31日跌幅明显，但成交量远低于8月28日，也仅略高于页面所列近期平均水平约387万股。

几个尺度的结论不同：

- 相对8月28日，单日回撤6.1%，触发硬信号。
- 相对8月21日财报后收盘，累计下降约3.1%。
- 相对8月20日财报前收盘，仍上涨约1.2%。
- 相对7月23日16.08美元，上涨约7.0%；最近一个月仍是温和上行，而非明确下跌趋势。
- 8月31日17.20美元较2025年9月17日52周高点20.98美元仍低约18%。

窗口内没有新的公司公告能够解释8月31日下跌。市场文章把回撤归因为财报后上涨、看多分析和期权热度后的获利了结；该来源为自动生成并经编辑审核的二级材料，只能作为市场叙事参考，不能作为事实因果证据。更可靠的事实是：价格在两个交易日内先放量上涨、再较低成交回吐，并最终回到财报前后区间。由此应保留而非推翻上次判断：二季度盈利改善是真实财务事实，但市场仍不愿在缺乏三季度验证时持续支付更高估值。

按上次约10.8亿稀释ADS量级粗算，17.20美元对应股权市值约186亿美元；二季度末560亿元人民币流动资金按财报汇率约83亿美元，简单扣除后企业价值约103亿美元。该估算没有扣除全部负债、受限资金用途或少数股东项目，不能当作精确估值；其意义只是说明价格回吐后，楼市、VIE/监管、利润率可持续性和现金可动用性的折价仍然很重。

## 未变化的经营判断

- 二季度四线贡献率提升、连续两个季度费用和毛利改善的证据仍成立；窗口内没有反证。
- 没有三季度GTV、收入、贡献额或门店生产率数据，因此14.6%调整后经营利润率仍只能视为旺季高点，而非稳态。
- 家装收入缩减、租赁净额确认、MAU及活跃经纪人/门店下降的问题没有新披露，既未恶化也未解决。
- 8月28日政策降低开发商尾部信用风险的方向性判断，尚不能覆盖全国1—7月房地产投资下降19.2%、新房销售额下降13.1%的弱需求基线。
- 上海8月21日起实施“以旧换新”购房补贴，且北京此前已放宽购房条件；一二手置换链条若活跃，理论上同时利于贝壳存量房和新房渠道，但窗口内没有成交数据足以量化效果。

## 风险、反证条件与下一轮跟踪

1. **政策执行风险：** 项目制开发贷款、开发商再融资和现房销售需要地方、银行及项目层面执行。若资金只流向少数项目、销售继续弱，贝壳应收与信用损失不会自动改善。
2. **佣金现金周期：** 现房销售可能减少坏账，却拉长从开工到销售的周期。应跟踪新房应收账款、账龄、信用损失拨备及经营现金流，而非只看GTV。
3. **淡季利润率：** 三季度调整后经营利润率若明显回落至2025年同期附近，将证伪“盈利中枢上移”；若仍显著高于去年且贡献额稳定，才足以进一步上调判断。
4. **平台网络健康：** 继续计算连接门店GTV、单活跃门店和单活跃经纪人产出，同时观察MAU、活跃门店及投诉/NPS，区分去低效产能和网络吸引力下降。
5. **新业务质量：** 家装合同额与退款、租赁在管套数/空置期/续租率仍是必要指标。净额确认提高利润率不等于贡献额持续增长。
6. **市场定价：** 若无新经营证据却持续突破20.98美元52周高点，应重新检查估值是否先于基本面；若在盈利持续兑现时仍跌破7月低位，则价格与基本面的偏离会进一步扩大。

下一次最迟复查可沿用原定2026年9月16日，重点观察8月房地产成交与政策执行初步数据；若这些数据仍不足，则等三季度业绩。提前触发条件包括：公司新增回购或股权激励、开发商重大信用事件、核心城市二手房成交突变、公司披露月度运营指标，或BEKE突破52周高点/跌破7月低位并伴随显著放量。
