# 中国平安（601318.SH）首次基线复查｜2026-09-04

## 复查结论

本轮应标记为**有实质变化（yes）**。重点变化窗口内，公司于2026年8月20日披露中报：归母营运利润同比增长8.3%，寿险及健康险新业务价值（NBV）增长11.2%，中期股息增长3.2%，说明寿险改革、多元渠道和分红险转型仍在产生价值；归母净利润增长36.1%则明显快于营运利润，不能外推为可持续的主业增速。股价在业绩公布后由8月20日的52.14元升至9月3日的58.00元，市场对结果做出积极重估。

基线判断是：平安已从寿险深度调整期进入“价值恢复但增速正常化”的阶段。2025年NBV高增奠定低谷修复基线，2026年上半年仍保持双位数增长，但较2026年一季度20.8%的增速明显放缓；代理人继续收缩而人均产能提升，非代理人渠道贡献接近四成，增长结构比过去更均衡。财险承保质量稳定、银行弱增长但资产质量暂稳，资管利润大增支持集团利润。当前最关键的分歧不是净利润是否漂亮，而是寿险NBV能否在高基数、利率下行和“报行合一”约束下持续增长，以及投资收益能否在权益市场波动中保持韧性。

## 过去一年基线

- 2025年集团归母营运利润1,344.15亿元，同比增长10.3%；扣非归母净利润1,437.73亿元，同比增长22.5%；归母权益首次超过1万亿元，较年初增长7.7%。全年现金分红总额488.91亿元，连续14年增长。
- 2025年寿险及健康险NBV为368.97亿元，同比增长29.3%，标准保费口径NBV率28.5%，同比提高5.8个百分点。代理人渠道NBV增长10.4%、人均NBV增长17.2%，银保渠道NBV增长138.0%；这表明价值恢复不再仅靠代理人，银保和社区金融成为第二增长支柱。
- 2025年产险原保费3,431.68亿元，同比增长6.6%，综合成本率96.8%，同比改善1.5个百分点；车险综合成本率95.8%，改善2.3个百分点。财险已回到“规模与承保利润兼顾”的正常状态。
- 2025年9月4日A股收盘57.50元，2026年9月3日收盘58.00元，未复权价格一年大致持平（约+0.9%）。考虑期间现金分红后总回报略高，但并未与经营指标改善同幅上升，说明估值修复仍受到长期利率、投资波动和集团复杂度折价制约。

## 最近30天的变化

### 1. 中报确认主业稳健，但净利润增速不可直接年化

2026年上半年营业收入5,751.38亿元，同比增长15.0%；归母净利润925.85亿元，同比增长36.1%；归母营运利润841.96亿元，同比增长8.3%；归母权益1.028万亿元，较年初增长2.8%。扣非归母净利润877.12亿元，同比增长19.2%。净利润与营运利润增速差距很大，且二季度利润受投资表现、去年同期基数及非经常性项目方向变化影响，因而8.3%的营运利润增长更接近可持续经营速度。集团综合偿付能力充足率198.1%，较年末提高4.8个百分点，没有出现资本约束恶化。

中期每股股息0.98元，同比增长3.2%。这比利润增长慢，但符合险企需要兼顾资本与股东回报的特征；稳定上调而非追随当期净利润跳升，也侧面说明管理层未将36.1%的利润增幅视为完全可重复。

### 2. 寿险价值继续增长，核心变化是“量增、率降、渠道更均衡”

上半年寿险及健康险NBV 248.47亿元，同比增长11.2%；用于计算NBV的首年保费增长19.0%，但标准保费口径NBV率由30.5%降至29.0%，下降约1.4个百分点。NBV增长低于保费增长，显示业务量扩张中价值率承压。公开点评显示一季度NBV增速为20.8%，因此二季度在高基数及银保监管深化下显著降速，这是本轮最需要持续观察的边际变化。

结构仍在改善：代理人渠道NBV增长5.4%，人均NBV增长14.1%，活动率提升5.6个百分点至55.5%，月均收入增长5.3%至10,418元；但期末个人寿险销售代理人为32.5万人，较年末下降7.4%。这是典型的“量减质升”，尚不能证明队伍规模已见底。银保渠道NBV增长18.0%至70.50亿元，银保、社区金融及其他渠道贡献接近四成、同比提高约3.8个百分点；社区金融渠道NBV增长109.8%。新业务分红险占比超过九成、代理人渠道长交期业务占比提高6个百分点，有利于降低保证成本、改善资产负债匹配，但也需要观察分红实现率和客户接受度。

保单质量尚稳：13个月继续率97.3%，同比提高0.4个百分点；25个月继续率95.8%，提高0.8个百分点。寿险及健康险营运利润仅增长2.3%至558.72亿元，慢于NBV，反映存量业务利润释放、假设与投资相关因素仍会影响当期表现。

### 3. 财险、银行稳定，资管是利润弹性来源

产险原保费1,787.51亿元，同比增长4.0%；综合成本率95.1%，改善0.1个百分点，车险综合成本率94.9%，改善0.6个百分点。新能源车险保费增长21.5%，但需持续跟踪其赔付率是否会吞噬规模增长。产险净利润同比下降12.4%至88.12亿元，说明承保指标小幅改善并未转换为净利润增长，投资等因素需要拆分观察。

平安银行上半年收入706.17亿元，同比增长1.8%，净利润256.96亿元，同比增长3.3%；净息差1.80%同比持平，不良率1.05%较年末持平，拨备覆盖率219.58%，下降1.30个百分点。判断仍是弱增长、资产质量表面稳定，不能把它作为集团加速增长引擎。

资管业务净利润96.58亿元，同比增长209.4%，是集团利润弹性的主要来源之一。保险资金组合6.61万亿元，较年初增长1.9%；上半年非年化净投资收益率1.4%，同比下降0.4个百分点，总投资收益率约2.5%、同比提高约0.6个百分点，综合投资收益率2.1%、同比下降约1个百分点。不同口径分化说明权益与OCI波动较大，不能仅用归母净利润判断投资端的长期质量。

### 4. 股价对中报作出积极反应，但一年维度仍未突破

截至复查时点最近完整交易日（9月3日），A股收58.00元。相较8月5日54.02元上涨约7.4%；期间先跌至8月18日51.32元，随后在8月20日中报后连续走强，8月21日、24日分别上涨2.32%和2.94%，9月1日和3日再上涨2.53%和2.42%，且多个上涨日成交量超过1亿股。中报后的量价配合说明市场把稳健营运利润、双位数NBV和分红增长视为正面信息。

但相对2025年9月4日57.50元，仅上涨约0.9%，过去一年仍属于区间震荡而非长期趋势突破。当前价格约为2026年6月末每股归母净资产56.78元的1.02倍；这是静态粗略P/B，不代表内含价值估值，但显示市场仍给予集团较强风险折价。价格与基本面的关系是“短期补涨、长期仍审慎”，尚不存在价格脱离基本面的过热信号。

## 经营逻辑与风险判断

正面证据包括：寿险NBV连续恢复且继续率高；代理人生产率和活动率提升；银保与社区金融降低单一渠道依赖；分红险和长交期产品改善负债成本与久期；财险COR保持95%左右；集团偿付能力与分红均稳健。医疗养老目前更像提升获客、留存和加保率的服务底座，而非独立利润引擎：上半年使用医养服务客户的加保率高出5.9个百分点，逻辑成立但仍需更多长期经济性证据。

主要反证与风险：一是NBV增速从一季度明显回落且价值率下降，若后续保费增长继续依赖较低价值渠道，价值增长质量会弱化；二是代理人数量仍下降，产能提升能否长期抵消人数收缩尚未确认；三是低利率会同时压低再投资收益并提高长期负债匹配难度，分红险转型只能缓释而不能消除；四是归母利润对权益市场、会计分类和基数敏感；五是平安银行息差与信用成本、地产及非标风险仍可能向集团传导；六是产险新能源车快速增长可能带来赔付率压力。

## 下一次复查重点

1. 2026年前三季度NBV增速、标准保费口径NBV率及二/三季度单季变化，判断本次降速是基数扰动还是趋势转弱。
2. 代理人数量、活动率、人均NBV和收入能否同时改善；银保与社区金融的NBV率、继续率和获客成本。
3. 分红险占比、长交期业务占比，以及负债成本和合同服务边际的变化。
4. 净投资、总投资和综合投资收益率之间的差异；OCI股票配置变化及净利润对市场波动的敏感度。
5. 产险尤其新能源车险的综合成本率；平安银行净息差、不良生成和房地产相关风险。
6. 股价能否在58元附近形成有效突破，或中报后的重估是否回吐；同时观察相对沪深300和同业险企的强弱。
