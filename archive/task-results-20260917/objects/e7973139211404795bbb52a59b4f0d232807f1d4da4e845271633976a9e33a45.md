# 九号公司二季度净利回升至8亿元，库存压力转向应收账款

九号公司8月11日披露的半年报，给上周股价大跌后留下的疑问提供了半个正面答案。公司上半年收入143.58亿元，同比增长22.28%，归母净利润10.08亿元，同比下降18.79%；但用半年累计数减去一季报，二季度收入约84.88亿元、归母净利润约8.05亿元，分别明显高于一季度的58.70亿元和2.03亿元。当天13时50分的行情扫描显示，股价较前收盘上涨约7.6%。这次上涨有明确的业绩催化，市场交易的首先是二季度经营修复，而不再是上周那种缺少新公告解释的价格波动（[2026年半年报](https://big5.sse.com.cn/disclosure/listedinfo/announcement/c/new/2026-08-11/689009_20260811_31IK.pdf)、[2026年一季报](https://money.finance.sina.com.cn/corp/view/vCB_AllBulletinDetail.php?id=12276831&stockid=689009)）。

修复最鲜明地体现在产品结构。服务机器人及配件上半年收入25.58亿元，已经超过2025年全年20.02亿元，毛利率约46.6%，成为公司当前最有价值的增长来源。相比之下，占收入约一半的电动两轮车收入74.93亿元，毛利率约17.2%，公司还以1.34亿元建店补贴冲减了这一品类的收入。也就是说，机器人正在抬高增长想象力，但两轮车仍决定整体规模，扩店和获客成本不会因为新品增长而消失。

报表利润的同比下降，也不能简单理解为产品经营恶化。上半年汇兑损益从去年同期收益2.57亿元变成本期损失3.71亿元，前后相差约6.28亿元，超过利润总额的同比减少额。剔除这一影响，主营经营并没有归母净利润下降18.79%看起来那么弱。不过，境外收入已占43.84%，境外业务毛利率又显著高于境内，汇率影响来自公司的全球化经营，而不是可以永久剔除的一次性项目。高毛利海外收入和外币敞口本就是同一枚硬币的两面。

## 库存下降，但现金考题只是换了位置

上周最值得警惕的是，九号公司2025年末产成品库存达到25.13亿元，经营现金流又明显受经营性应付增加支撑。半年报给出的好消息是，总存货较年末下降20.09%至25.30亿元，其中产成品降至18.39亿元。收入继续增长而厂内库存下降，至少说明增长并非靠继续堆积成品完成。

但营运资金压力没有消失，而是转向了渠道和回款。半年末应收账款较年末增加78.25%至26.72亿元，应收增速远高于收入增速；应付账款也增加50.34%至42.79亿元，应付票据仍有52.08亿元。上半年经营现金流虽然达到19.67亿元，高于净利润，却同比下降46.14%，而且其中包含存货减少、经营性应付增加和受限资金减少的贡献。把这些变化合在一起看，更准确的结论是库存风险阶段性缓解，但公司仍在大量使用供应商信用，同时把更多资金压在应收端，现金转化质量尚未真正过关。

费用同样提醒投资者不要把二季度直接年化。上半年销售费用增长33.12%，研发费用增长43.68%，均快于收入；综合毛利率约为28.6%，同比下降约1.8个百分点。机器人、海外产品和新门店需要前置投入，这些投入可能支撑下一阶段增长，但截至半年末，规模扩张尚未形成稳定的经营杠杆。

因此，这份中报改变的是对短期经营节奏的认识：一季度不是可以外推全年的低点，二季度的收入、利润和现金流恢复是真实的；它没有改变对增长质量的检验标准。下一步比单季增速更重要的，是应收账款能否在旺季回落、服务机器人的高毛利增长能否延续，以及外汇损益、套保结果与海外利润合并后究竟留下多少现金。九号公司已经证明库存可以降下来，现在还要证明降下来的库存没有只是变成更慢的回款。
