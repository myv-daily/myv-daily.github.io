# 中国广核（003816.SZ / 01816.HK）首次基线复查 — 2026-08-23

## 结论与变化判定

**判定：存在值得公开写作 Agent 考虑的实质变化（yes）。** 近 30 天形成了“新机组投产 + 后续项目获核准 + 低成本再融资”的同向组合：惠州2号于8月3日具备商业运营条件，使公司管理在运装机由34,248MW增至35,450MW（+3.51%）；惠州5、6号于7月31日获核准，合计2,434MW，且采用华龙一号2.0版；8月20日又发行两期合计36亿元、3年期、票息1.56%的中票用于子公司偿债和补流。这一组合提高了未来装机成长的可见度，也确认公司将长期处于高资本开支、高杠杆扩张阶段。融资利率低且主要是债务置换，因此36亿元中票单独看不是流动性恶化信号；真正改变判断的是它与项目投产、核准密集出现，显示资产扩张和融资需求都在加速。

短期经营仍弱于扩张叙事：2026年上半年总发电量1,177.66亿千瓦时，同比下降2.12%，商运上网电量1,095.97亿千瓦时，同比下降3.32%；2026Q1收入163.19亿元、归母净利润27.41亿元，分别同比下降13.25%和9.33%。因此目前不是“业绩已经反转”，而是“新增装机开始兑现、存量机组电量与电价仍需验证”。

## 业务和行业基线

公司是中广核集团旗下核电运营上市平台，核心收入和利润来自核电销售，兼有工程建设及技术服务。核电业务的经济性由在运装机、利用小时、计划/非计划停机、大修节奏、市场化交易电量与价差共同决定；新机组从核准、FCD、建设、调试到商运周期长，前期资本开支巨大，投运后才逐步贡献电量和现金流。

截至2025年末，公司管理28台在运机组、31,838MW；上市公司口径在建16台、19,376MW，另受控股股东委托管理在建4台、4,846MW。与2024年末相比，上市公司口径在建数量和容量近乎翻倍，主要来自2025年完成惠州核电、苍南核电等五家公司股权收购及多个项目FCD。2025年公司运营管理机组总发电量2,470.13亿千瓦时，同比增长2.00%，上网电量2,326.48亿千瓦时，同比增长2.36%。全国层面，2025年核电平均利用小时7,809小时，同比增加126小时；政策继续强调“积极安全有序发展核电”，行业中长期需求和项目储备基线稳固。

公司的核心优势是大规模成熟机组运营能力、华龙一号批量化建设经验和央企融资能力；核心约束是核安全不可容错、工程延期或超支风险、区域电力市场化交易带来的电价压力，以及新项目长期占用资本。控股股东资产注入会扩大上市公司装机与利润基础，但也可能同步推升合并债务、少数股东权益和折旧负担，不能只按装机增量理解为即时增厚。

## 过去一年经营与财务基线

2025年因同一控制下合并而重述后，公司收入756.97亿元，同比下降4.11%；归母净利润97.65亿元，同比下降9.90%；扣非归母净利润91.13亿元，同比下降15.13%；经营现金流299.71亿元，同比下降20.09%。2025年末总资产5,056.56亿元、负债3,294.42亿元，资产负债率65.15%，较重述后的2024年末上升3.95个百分点；流动比率66.14%，低于上年87.92%。公司仍为AAA主体、未出现有息债务逾期，现金创造能力可观，但财务缓冲较此前下降。

2026Q1表现继续承压：收入163.19亿元，同比下降13.25%；归母净利润27.41亿元，同比下降9.33%；扣非归母净利润26.58亿元，同比下降9.12%。经营现金流34.78亿元，同比增加44.18%，但单季现金流受结算节奏影响，不宜据此判断全年改善。期末总资产5,302.86亿元，较2025年末增加4.87%；按总资产减股东权益推算，合并负债约3,499亿元，资产负债率约66.0%，延续上升趋势。宁德第二核电自2026年1月5日起纳入合并报表，是总资产、负债和同比口径变化的重要原因。

公司2026年度投资计划总额864.3亿元，明显高于2025年经营现金流299.7亿元，虽不等同于全部由上市公司当年现金支付，但足以说明自由现金流仍将受压，外部融资会常态化。2025年已发行49亿元广核转债，2026年4月两期中票合计20亿元、票息1.63%，8月两期中票合计36亿元、票息进一步降至1.56%。低票息和AAA信用显示融资渠道通畅，债务期限由短期借款向3年中票置换有利于成本和期限管理；但应继续追踪短债占比、资本化利息、净债务和年度偿债现金流，而不能把低利率等同于低杠杆风险。

## 重点变化窗口（2026-07-24至2026-08-23）

### 1. 惠州2号商运：近期最直接的盈利增量

事件发生于2026年8月3日，公司8月4日公告：惠州2号完成全部调试并具备商业运营条件，单机1,202MW，使管理在运机组增至31台、35,450MW。相对投运前34,248MW，容量增加3.51%。按公司披露的2025年国内核电平均利用小时测算，惠州一期两台机组年发电量可超过180亿千瓦时；但惠州2号在2026年只贡献约五个月，且初始负荷爬坡、电价、折旧、财务费用与少数股东分配将决定实际利润增量。下一次财报应重点看惠州核电收入、净利润和利用小时，而非只看管理装机。

### 2. 惠州5、6号获核准：成长久期延长，也锁定更长资本开支周期

事件发生于7月31日并于8月1日公告，两台机组合计2,434MW，采用华龙一号2.0版，尚须取得建造许可证后才能FCD。这不是近期利润，但把惠州基地的长期扩建从项目储备推进到已核准阶段，提升2030年代装机增长的可见度。代价是建设支出、工程风险和融资需求进一步延长，当前估值不应把全部核准容量按成熟在运资产资本化。

### 3. 36亿元中票：低成本债务置换，不是孤立的流动性警报

公司8月20日发行26广核电力MTN003和MTN004，各18亿元，均为3年期、票息1.56%，8月21日到账，用于子公司偿还借款及补充流动性。较4月发行的两期3年中票1.63%再下降7bp，表明融资条件仍然宽松。相对于2025年末3,294亿元总负债，36亿元约为1.1%，规模不足以单独改变偿债判断；但加上2026年864.3亿元投资计划，其信息含义是融资需求将持续、母公司正主动统筹子公司负债。需在2026中报中核对募集资金对应的原借款利率和期限，判断是真正降低利息成本/拉长期限，还是新增净融资。

### 4. 电量尚未验证增长，价格对利好反应偏弱

2026年上半年公司发电量同比下降2.12%、上网电量下降3.32%，降幅略差于同期全国核电发电量下降2.75%与上网电量下降2.82%的行业表现（发电量略优、上网电量略弱）。公司解释二季度按计划完成3个年度换料大修和2个十年大修，具有节奏性，但惠州新机组能否在下半年覆盖存量机组大修及市场交易压力仍待三季报验证。

A股8月21日收3.84元，较7月24日4.06元下跌5.4%；8月3日惠州2号商运前后股价一度到4.16元，随后回落。市场没有持续追价，反映投产与核准利好已被资本开支、短期电量/利润下降和估值约束抵消。以2025年EPS 0.193元和每股净资产约2.44元计，3.84元对应约19.9倍历史PE和1.57倍2025年末PB（按2026Q1每股净资产约2.49元则约1.54倍PB）；2025年度每股股息0.086元对应静态股息率约2.24%。这一估值并非明显压力情景定价，后续需要利润恢复兑现。

## 风险、反证与待验证问题

1. **电价而非单纯电量可能成为主要变量。** 核电参与市场化交易的比例和价差若恶化，新机组增量可能被存量资产电价下降抵消。按基地追踪平均结算电价、市场化比例及辽宁核电机制电价能否向广东、广西、福建扩散。
2. **大修与非计划停机需区分。** 上半年电量下降可由计划大修解释，但若三季度存量基地利用小时仍弱，应排查非计划停机、台山机组状态和区域需求/消纳，而不能继续归因于季度节奏。
3. **资本开支与资产注入可能稀释自由现金流。** 重点核对2026中报资本开支、购建长期资产现金支出、净新增有息债务、利息费用和少数股东损益；关注苍南等后续资产注入价格与融资方式。
4. **新机组盈利曲线可能低于装机推算。** 惠州1、2号需验证实际利用小时、上网电价、折旧年限、财务费用及首年检修安排；惠州5、6号尚未FCD，投产时间很远。
5. **可转债稀释。** 广核转债49亿元，转股价经分红调整后需持续跟踪；股价接近或高于转股价时，潜在转股会增加股本，但也降低债务。
6. **核安全和工程质量为尾部核心风险。** 任一重大安全事件、关键设备缺陷或工程延期都可能同时影响发电、资本开支、监管节奏和估值。
